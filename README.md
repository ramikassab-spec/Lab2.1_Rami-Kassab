# Visuell – bildbehandling

En responsiv webbplats skapad som en del av en laboration i bildbehandling vid Mittuniversitetet.

Webbplatsen presenterar redigerade fotografier och jämför dem med originalbilderna. Bilderna har bearbetats i Photopea.

## Webbplatsens sidor

- **Start:** introduktion, bildserie och beskrivning av arbetsprocessen.
- **Bilder:** före- och efterbilder med förklaringar till redigeringarna.
- **Om mig:** presentation av mig, min utbildning och arbetet med projektet.

## Tekniker

- HTML5 för sidornas struktur.
- CSS för layout och utseende.
- Mobile first och media queries för responsiv design.
- Flexbox och CSS Grid för placering av innehåll.
- Git och GitHub för versionshantering.

## Bildbehandling

Arbetet omfattar retuschering, färgkorrigering, justering av ljus och kontrast, beskärning, storleksanpassning och friläggning.

Fotografierna används i JPEG-format, porträttet i PNG med transparens och logotypen i SVG-format.

## Projektstruktur

- `index.html` – startsida
- `bilder.html` – bildjämförelser
- `om.html` – presentation
- `css/style.css` – gemensam stilmall
- `images/` – bilder, logotyp och favicon

## Kör projektet lokalt

Öppna projektmappen i Visual Studio Code och starta `index.html` med tillägget Live Server.

## Kontroller

- Alla tre HTML-sidor har godkänts i W3C:s HTML-validator.
- CSS-filen har godkänts i W3C:s CSS-validator.
- Alla tre sidor har kontrollerats vid mobilbredden 390 px.
- Webbplatsens utseende har även granskats på större skärm.
